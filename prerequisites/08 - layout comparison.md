## Layout A — Classic Dash (ignition bottom-left)

```
FAR EDGE
[WIPERS] [LIGHTS]                    [RADIO]
[HB][BEA][HAZ] [DIFF][AXLE][CRUISE]
[PARK BRAKE][TRAILER BRAKE]  [WIN L][WIN R]
[CRUISE +/-]      [TRAILER ATT][DASH][AUD PREV]
[HORN][AIR][LT HORN][ACT][WIPER BACK]
[IGNITION]
FRONT EDGE
```

- Everything in tidy horizontal rows — easiest to build and label.
- Ignition tucked in the bottom-left corner, near the front edge, like
  reaching for a key while seated.
- Brakes sit in the middle of the panel — the most-grabbed controls stay
  central, horns at the front edge.

Pros: simplest panel to drill, symmetrical, classic layout.
Cons: a bit plain; lights and chassis toggles share one row.

## Layout B — Split Console (ignition bottom-right)

```
FAR EDGE
[WIPERS] [LIGHTS]                    [RADIO]
[HB][BEA][HAZ]        [DIFF][AXLE][CRUISE]
[WIN L][WIN R]        [PARK BRAKE][TRAILER BRAKE]
[CRUISE +/-]   [TRAILER ATT][DASH][AUD PREV]
[HORN][AIR][LT HORN][ACT][WIPER BACK]    [IGNITION]
FRONT EDGE
```

- Left half = CAB controls (lights, wipers, windows).
- Right half = CHASSIS + AUDIO (diff, axle, cruise, brakes, radio).
- Ignition in the bottom-right corner, mirror image of Layout A.

Pros: strong mental grouping — your left hand drives the cab, right hand
handles chassis/audio. Good if you drive right-handed with the mouse.
Cons: brakes are on the right side, away from the "default" left-hand
parking-brake reach.

## Layout C — Cockpit Cluster (ignition bottom-left)

```
FAR EDGE
[WIPERS] [LIGHTS]                    [RADIO]
[HB][BEA][HAZ]        [DIFF][AXLE][CRUISE]
[PARK BRAKE][TRAILER BRAKE] [WIN L][WIN R]
[CRUISE +/-]  [TRAILER ATT][DASH][AUD PREV]
[HORN][AIR][LT HORN][ACT][WIPER BACK]
[IGNITION]
FRONT EDGE
```

- Same parts as A but re-spaced: toggles split into two breathing groups,
  brakes pulled toward center, windows pushed to the right side.
- Ignition bottom-left.

Pros: more air between clusters, feels less crowded than A.
Cons: nearly identical layout to A — only worth it if you prefer the
spacing/grouping.

## Recommendation

Pick A if you want the cleanest build (simple drill pattern, easy labels).
Pick B if you want the cab/chassis mental split (left hand cab, right hand
chassis) — this is my favourite for driving ergonomics.

If you pick A or C, ignition stays bottom-left. If B, bottom-right.

## Checklist before cutting

1. Actual enclosure size (adjust spacing, not structure)
2. Push buttons plain or LED-ring (affects LED count)
3. Material + label method
4. Confirm ignition corner choice
